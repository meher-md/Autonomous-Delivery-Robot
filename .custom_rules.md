# User Preferences & Rules

## coding_workflow
- **Strict Approval Required:** Before making ANY code changes (write, edit, delete), the agent MUST:
  1. Explain the problem clearly.
  2. Propose the solution plan.
  3. **WAIT** for explicit user approval (e.g., "ok", "go ahead").
  - **Exception:** Only verification commands (read/list/echo) are allowed without prior approval.

## communication_style
- **Explain First:** Always explain the "Why" and "What" before the "How".
